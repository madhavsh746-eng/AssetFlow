# 🚀 AssetFlow - Enterprise Asset & Resource Management System

AssetFlow is a modern Enterprise Asset & Resource Management System built to simplify how organizations manage their physical assets, shared resources, maintenance workflows, and audits.

This project is being developed as part of a Hackathon using the MERN Stack.

---

## 📌 Problem Statement

Organizations often manage assets using spreadsheets and manual processes, leading to:

- Asset mismanagement
- Double allocation
- Resource booking conflicts
- Poor maintenance tracking
- Limited operational visibility

AssetFlow solves these problems through a centralized ERP platform.
