# 🚀 AssetFlow

## Enterprise Asset & Resource Management System

AssetFlow is a modern Enterprise Asset & Resource Management System developed using the **MERN Stack**. It helps organizations efficiently manage assets, resource allocation, maintenance workflows, audits, and bookings through a centralized platform.

---

## 📌 Project Overview

AssetFlow provides organizations with a centralized ERP platform to:

- Manage departments and employees
- Register and track assets
- Allocate assets to employees
- Book shared resources
- Manage maintenance requests
- Conduct asset audits
- Generate reports and analytics
- Receive real-time notifications
